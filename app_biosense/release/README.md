# APK BioSense

## Archivo disponible

- `BioSense-v1.0.0-debug.apk`: APK universal instalable para pruebas en Android.

Este APK usa la firma de depuración del proyecto. Para publicar la aplicación
en una tienda se debe configurar una clave privada y generar un APK o AAB de
producción con `flutter build apk --release` o `flutter build appbundle`.
